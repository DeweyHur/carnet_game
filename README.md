# 카르네(Carnet): 한 정거장씩, 파리 여행


첫 화면은 **실제 파리 지하철 노선을 따라가는 여행**입니다. 루브르→에펠탑(1→6호선), 루브르→몽마르트르(1→12호선), 트로카데로→비르아켐(6호선) 세 코스를 제공합니다. 모든 정차역과 종점 방향을 표시하고 환승역에서는 명시적으로 갈아탑니다. 역당 3.5초의 압축 체험이며 실제 운행 영상·실시간 길찾기가 아닙니다.

실제 역과 여행지 사진, 하차 후 도보 안내, 여행 메모, 로컬 사진 엽서 저장을 제공합니다. 2026년 공식 교통권 안내와 성인·공항 제외 1회권/1일권 비교 계산기를 포함합니다. 요금 확인일은 2026-09-07이며 출발 전 공식 앱에서 운행 상황을 확인해야 합니다. `src/data/metro.ts`에서 코스와 출처를 관리합니다.

기존 19개 도시 콘텐츠는 상단 **여행 수첩**에서 이어갑니다. 기존 세이브를 읽을 때 현재 게임에 필요한 필드만 복원하며, 여행 진행·예산·앨범은 유지합니다. 지하철 코스는 무료 미리보기로 기존 미션 예산과 분리되어 있습니다. 정밀 노선이 없는 기존 도시 내 이동은 장소 지도와 현지 이동 안내로 진행합니다.

검증: Node 22.12 이상에서 `npm run build`, `npm test`, `npm run lint`. 지하철 정차역·환승 연결, 교통권 비교, 사진 파일·저작권 정보, 이전 저장 호환성을 검사합니다.

`Carnet_게임개발계획서_v0.9.md`의 6장(샘플 콘텐츠·MVP)을 플레이 가능한 웹 프로토타입으로 옮긴 것입니다.
일드프랑스 6개 도시 + 프랑스 북부·중부 6개 도시, 그리고 국경 너머 7개 도시(런던·브뤼셀·쾰른·베를린·제네바·바르셀로나·마드리드)까지 총 19개 도시. 이야기 13개 + 국경 도시 이야기 7개 + 도시별 사진 취재·미식 체험 38개를 더해 총 58개 미션을 제공합니다.

> **지금 어디까지 구현됐고 뭐가 남았는지**는 [`ROADMAP.md`](./ROADMAP.md)에서 기획서 섹션별로 추적합니다. 이 저장소를 다시 열 때는 그 문서를 먼저 읽고, 완료한 항목은 지우고, 새로 한 일을 적어 넣습니다.

**여행 수첩에서는 세계지도로 도시를 탐색합니다.** 지도는 두 겹입니다. 도시 간 이동은 **세계지도**(핀·노선·안개·범례)가 무대이고, 도시 안으로 들어가면 그 도시의 **내부 지도**(`CityMap`)가 무대가 됩니다. 여행 수첩을 시작하면 세계지도가 열립니다 — 여행의 본체는 지도 위에서 핀을 고르고 노선을 잇는 것입니다. 지도에는 티어(S/A/H)·잠긴 지역의 "안개"·진행률·지역 바로가기를 보여주는 범례가 떠 있고, 잠긴 지역은 각 도시 주변에 반투명한 안개로 표시되다가 해금되면 걷힙니다(기획서 §3.1). 진행 중인 미션이 있으면 지도 위에 떠 있는 "다음 취재" 카드로 바로 이어갈 수 있습니다. 줌아웃해서 유럽 전체를 보면 번잡함을 줄이려고 메인 무대(S) 도시 이름만 남고 거점·유산 도시는 점으로만 표시되며, 확대하면 다시 전체 이름이 나타납니다.

도시 하나를 열면(도시 카드 › "사진 산책" 탭) 그 도시의 실제 장소들이 좌표를 가진 핀으로 지도 위에 놓입니다. 파리는 20개 구(1구 루브르부터 20구 메닐몽탕까지) 라벨도 함께 떠 있습니다. 미션 중 "방문" 스텝에 들어서면 사진 대신 이 내부 지도가 장면의 배경이 되어, 지금 찾아가야 할 장소가 지도 위에서 크게 펄스로 강조됩니다 — 지도가 사진 뒤에 숨는 장식이 아니라 미션이 실제로 벌어지는 무대가 되도록 한 것입니다.


큰 현장 사진과 도시 엽서 목록에서 여행을 시작하고, 지도 보기로 동선을 확인합니다. 사진 산책에서 장소를 방문하거나 현지 음식을 맛보면 사진과 방문 기록이 앨범에 쌓입니다. 사진은 확대할 수 있으며 촬영자·라이선스·원본 링크를 함께 표시합니다.

가격 맞추기는 직접 입력 없이 네 가지 가격표 중 하나를 고르는 방식입니다. 영수증에서 실제 가격, 자국 통화 환산액, 예상가와의 차이를 확인합니다. 답안·구매·기사 결과는 저장되므로 잠시 접거나 새로고침해도 결제와 보상이 중복되지 않습니다. 기존 `carnet-save-v1` 저장을 유지합니다.

**라이벌 테오와 국경 너머.** 불로뉴비양쿠르의 메인 미션 「지구의 기록」을 마치면, 라이벌 작가 테오가 끼어들어 런던·브뤼셀·쾰른·베를린·제네바·바르셀로나·마드리드로 먼저 떠났다고 선언합니다. 이 순간 프랑스 북부·중부의 소도시들과 함께 일곱 국경 도시가 한꺼번에 지도에서 열리고, **테오와의 경주**가 시작됩니다 — 테오는 도시마다 정해진 날짜에 "도착"하고, 그 전에 플레이어가 먼저 그 도시의 스탬프를 찍으면 특종 보너스(원고료 +€20, 평판 +2)를, 늦으면 특종 없이 기록만 남습니다. 각 도시 카드와 수첩 › 여권 탭에 테오와의 거리(D-day 또는 이미 도착했는지)가 표시되므로, 아미앵·랭스 같은 소도시부터 걸을지 국경으로 서두를지는 이 정보를 보고 플레이어가 정합니다. 런던(파운드)과 제네바(스위스 프랑)는 진짜 환전이 필요한 국경이고, 브뤼셀·쾰른·베를린·마드리드는 국경을 넘어도 유로를 그대로 쓰는 "화폐가 같은 국경"입니다(기획서 §3.3). 쾰른↔베를린, 바르셀로나↔마드리드처럼 파리를 거치지 않고 국경 지역 안에서 바로 이동하는 노선도 있습니다.

**한국어·English.** 첫 지하철 화면과 게임 HUD의 KO/EN 버튼으로 전환합니다. 58개 미션의 대사·퀴즈·편지, 역사 카드, 음식 설명, 사진 제목·확대 화면, 지도 핀, 교통권 안내와 계산기를 모두 번역합니다. 언어는 저장되고, 표시할 때만 번역하므로 미션 정답·수집품·기존 저장 데이터는 바뀌지 않습니다. `src/data/english.json`과 `src/i18n.ts`가 번역 사전이며, `npm test`는 전체 콘텐츠와 568개 영문 화면·미션 단계를 렌더링해 한국어 누락을 검사합니다. 사용자 입력 이름과 사진 원본 속 글자는 번역 대상이 아닙니다.

## 실제 사진

`public/photos/`의 WebP 사진과 작은 썸네일을 배포에 포함합니다. 플레이 중 Wikimedia에 사진 요청을 보내지 않습니다. 다운로드 재현은 Python 3 + Pillow 환경에서 `python scripts/fetch_photos.py`로 가능합니다. 기존 파일은 건너뛰며, 교체는 `--refresh 사진ID`를 사용합니다.


지도 타일은 OpenFreeMap(무료 공개 스타일)을 쓰고, 네트워크가 막히면 내장된 프랑스 윤곽 폴백 스타일로 자동 전환합니다.
실서비스에서는 기획서 §3.1대로 PMTiles 자체 호스팅으로 교체하면 됩니다(`src/ui/MapView.tsx`의 `STYLE_PRIMARY`).

## 다중 통화 시스템

12개 프랑스 도시는 모두 유로(EUR)를 쓰지만, 국경 너머 7개 도시는 실제 통화가 다릅니다: 런던은 파운드(GBP), 제네바는 스위스 프랑(CHF), 브뤼셀·쾰른·베를린·바르셀로나·마드리드는 프랑스와 같은 유로입니다. `City.currency` 필드로 지정하며, 입장료(`feeEur`)·음식 기준가(`baseEur`)·숙박비(`hostelEur`)·구역 1회권(`transitFareEur`)은 모두 **그 도시의 실제 통화 기준 금액**으로 입력합니다(필드 이름은 하위 호환을 위해 그대로 뒀습니다). 도시 간 열차·유로스타 요금(`Edge.fareEur`)만은 실제 국제선 관행대로 항상 유로로 판매되는 것으로 통일했습니다. 지갑 부족 시 카드 결제(자국 통화, 수수료 1.5%) → 편집장 선지급(€300 상당, 이자 10%) 순으로 처리되며, 어느 통화로 결제하든 동일한 로직(`store.ts`의 `pay()`)을 씁니다.


- **내비게이션:** 주행 화면의 지도 버튼을 누르면 일시정지하고 실제 도시 경로를 봅니다. OSRM 도로 경로 위에서 차가 진행도에 맞춰 이동하며, 출발지·목적지·주변 명소·남은 거리를 표시합니다. 지도 타일까지 끊기면 로컬 POI 좌표와 직선 안내가 표시됩니다. 아케이드 풍경은 창작이며 실제 도로의 차선·건물을 재현하지 않습니다.
- **진행:** 성적표에서 바로 재도전하거나 취재를 이어갑니다. 기존 이동비·시간은 그대로 적용됩니다. 자유 주행은 게임 시간 15분을 사용합니다.

## 사운드


외부 음원 파일은 하나도 쓰지 않습니다. 모든 효과음과 배경음은 `src/audio.ts`가 Web Audio API로 그 자리에서 합성합니다 — 라이선스 걱정이 없고, 인터넷 연결 없이도(지도 타일과 달리) 완전히 동작하며, 번들 용량도 늘지 않습니다.

- **효과음**: 사실 카드 수집, 퀴즈/포토/순서 퍼즐 정답·오답, 음식 구매(카드 결제음), 장소 방문(문 여닫는 소리), 도시 간 열차 출발·도착, 여권 스탬프, 테오와의 경주 승패, 수첩 여닫기 — 각각 오실레이터·노이즈 버스트를 짧게 조합해 만든 고유한 소리입니다.
- **배경음**: 게임을 시작하면 낮은 화음 패드와 느린 아르페지오가 은은하게 흐릅니다. 정식으로 작곡·녹음된 트랙이 아니라 절제된 절차적 합성이며, 정식 서비스에서는 라이선스가 확인된 실제 음원으로 교체하는 편이 낫습니다.
- **음소거**: HUD 오른쪽 위 🔊/🔇 버튼으로 언제든 끄고 켤 수 있고, 이 설정은 저장됩니다(`store.ts`의 `muted`). 브라우저의 자동재생 정책 때문에 페이지를 열자마자는 소리가 나지 않으며, 첫 클릭·키 입력 한 번으로 오디오가 깨어납니다.

## 미션 스텝 추가하기

`src/data/missions.ts`의 `steps` 배열에 스텝을 넣으면 됩니다. 스텝 타입은 `src/game/types.ts`의 `Step`:

| 타입 | 설명 |
|---|---|
| `say` | 대사. `who`: margot / guide / L / theo / echo / narrator. echo는 `fiction` 플래그로 창작/인용 표시 |
| `card` | 사실 카드 수집 (`cardId`는 `cards.ts`에 있어야 함) |
| `quiz` | 3지선다. 정답이든 오답이든 카드는 주고, 오답은 기사 정확도에 반영 |
| `photo` | L.의 사진 ↔ 현재 장소 매칭 |
| `order` | 순서 퍼즐. `items`는 정답 순서(UI에서 섞음) |
| `visit` | 장소 방문: 입장료·소요 시간·휴관 요일(실제 데이터) 검사, 22시 이후 불가 |
| `buy` | 음식 구매. `guess: true`면 가격 맞히기(오차가 KPI로 기록됨) |
| `exchange` | 환전(환전 경로 선택). `from`/`to` 통화를 지정 — 런던·제네바처럼 실제 환전이 필요한 도시에서 쓴다 |
| `article` | 사실 카드로 기사 조립 → 등급(C/B/A/S) → 원고료 |
| `letter` / `unlock` / `collect` / `stamp` | L.의 편지 / 지역 해금 / 수집품 / 여권 스탬프 |
