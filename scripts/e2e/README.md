# 메인 이벤트 끝까지 플레이해 보기(머리 없는 브라우저)

봇이 진짜 키(W·E·숫자·Space)를 보내며 사람처럼 한다 — 맡긴 사람에게 걸어가 말을 걸고, 벽을 정면으로 보고 올라가고, 턱에서 기력이 찰 때까지 쉬고, 사진을 찍고, 떨어지다 글라이더를 펴 돌아가 보고한다. 카메라 방위만 직접 돌린다(마우스 대신).

```sh
npx vite --port 5173 &                     # 개발 서버
PW_MODULES=$(npm root -g)/ node scripts/e2e/run.mjs eiffel   # arc · louvre · nd · sc · finale
```

- 걸리는 시간: 에펠탑 약 7분(스물세 단), 나머지 3~5분. 한 번에 하나씩(4코어에서 여럿을 함께 돌리면 시작부터 시간 초과).
- 걷는 동안엔 그리기를 끈다(`stopRender`). 헤드리스 크롬은 화면이 안 바뀌면 프레임을 만들지 않아서, 작은 점 하나를 CSS로 계속 움직이고 `--disable-frame-rate-limit` 등으로 띄운다.
- 테스트 중에 소스를 고치면 Vite가 페이지를 다시 읽어 판이 날아간다.
- `finale`은 다섯 메인을 끝낸 것으로 두고(각자 따로 확인) 시계를 밤 9시로 돌려 본다.
